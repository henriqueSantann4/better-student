# Better Student: app de celular

Ainda não iniciado. Previsto para a **fase 3** do roadmap.

- **Stack:** React Native + Expo (TypeScript), reaproveitando `packages/shared`.
- **Plataforma inicial:** Android. O iOS vem depois, compilado pelo GitHub Actions (macOS) e instalado via AltStore/SideStore.
- **Função exclusiva:** foto do quadro, enviada automaticamente para a pasta da disciplina no PC.
